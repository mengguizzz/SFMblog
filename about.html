关于这个演示站

一个零数据库的单文件 Markdown 博客 —— 这里是它的在线演示。

Hello, World.

这里是 SFMblog 的演示站。

整个博客没有数据库：文章是 blogs/default.md 一个文件， 评论是 comments/ 下的一堆 JSON。 备份博客就是复制一个文件夹。

它有什么

  • 📄单文件 Markdown 数据库，不需要 MySQL
  • 🖥️后端只有一个 api.php，其余全是静态文件
  • 💬自实现的评论：审核 + 蜜罐 + 限流，不依赖第三方
  • 🎨极光玻璃界面、白天黑夜、文章目录与阅读进度
“备份博客，就是复制一个文件夹。”

演示站的边界

  • ✅界面、动效、白天黑夜、文章渲染、看板娘、一言 —— 都能玩
  • ⚠️文章列表与评论要靠 api.php： 纯静态托管（比如 GitHub Pages）上看不到，部署到支持 PHP 的服务器就正常了
  • 🔒后台控制台只在服务器环境可用，演示站不开放

想在自己机器上跑起来，看仓库 README 的「快速开始」—— 生成密码哈希、填 config.php、配一段 Nginx，就完事了。

Tech Stack

前端
原生 HTML / CSS / JS Marked.js Highlight.js
后端
PHP 8 单文件 Markdown 无数据库
部署
Nginx / OpenResty PHP-FPM 无需构建

Live2D Marked.js Highlight.js 一言 API
